# Carousel com SwiperJS — Aula 08

Projeto-base seguindo a estrutura mostrada no slide: Next.js + TypeScript + Tailwind CSS.

## 1. Instale o Swiper
No terminal, dentro do projeto Next.js:
```bash
npm install swiper
```

## 2. Copie os arquivos
Copie `app/data/slideData.ts` e `app/components/Carousel.tsx` para as pastas correspondentes.
Copie `app/page.tsx` e `app/globals.css` para a pasta `app/` (ajuste o CSS se seu projeto já tiver estilos).

## 3. Execute
```bash
npm run dev
```
Abra http://localhost:3000.

> As imagens de exemplo usam URLs públicas do Unsplash. Para usar imagens próprias, coloque-as em `public/images/` e troque os valores de `image` em `slideData.ts` por caminhos como `/images/carro.jpg`.
